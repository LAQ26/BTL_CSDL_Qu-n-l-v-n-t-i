# Hệ Thống Quản Lý Hãng Vận Tải Hành Khách Đường Dài (Project 5)
## Hướng dẫn cài đặt & chạy ứng dụng
1. Khởi động MySQL (XAMPP), tạo CSDL và chạy file `QuanLyVanTai.sql`.
2. Cài đặt thư viện: `pip install -r requirements.txt`
3. Chạy ứng dụng: `streamlit run app.py` (Tài khoản mặc định: `admin` / `123456`).
